Correctness fixes
- Advanced tool output/files/translation become invalid as soon as relevant options, text, source image or count markers change. Prevents saving an old image with new physical dimensions or sharing stale Office files.
- Photo inputs decoded at original pixel dimensions with EXIF orientation. Erase/colored-mark tools no longer silently cap output at 2400px. Explicit 48-megapixel input budget rather than silent quality reduction.
- Multi-page PPT exports render/encode one original-size page at a time; no 1200px intermediate JPEG. Package size limit remains explicit.
- Excel OCR builds common horizontal column anchors across rows and keeps leading/interior empty cells. It remains a text-table heuristic, not merged-cell or arbitrary table reconstruction.
- Cancellation reaches detached CPU workers, checks processing loops, and rejects canceled outputs before publishing. Phase/page counts and a Cancel action appear while processing. System Vision/CI calls may finish their current stage before cancellation completes.
- Image encoding moved off the main actor. Colored-mark pixel processing avoids per-pixel array allocations.
- Book curve adjustment maps full vertical strips instead of cropping away top/bottom content.
- Prepared exports/results have scroll targets, and text editing ends before generation. Empty option sections removed.
- Large accessibility text uses a scrolling purchase footer so the fixed disclosure cannot obscure the page.
