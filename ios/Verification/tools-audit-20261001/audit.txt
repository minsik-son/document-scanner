우선 수정할 문제 (코드 근거)
P1 결과와 설정의 불일치:
AdvancedOfflineToolsView.swift:192–218,254–280,324–402.
옵션 strength/curve/split/twoPages/photoSize/blue/selection/offsets와 text/from/to/editableSlides/allPages 변경 시 이전 output/files/translated 무효화가 없다.
Save PDF copy는 saved만 검사하고 output을 그대로 사용한다. 새 설정으로 Preview result/Create Office file을 다시 누르지 않으면 이전 결과를 저장/공유할 수 있다.
예: 35×45mm 인물 결과 생성 후 2×2in 설정 변경 → saveCopy는 새 규격과 이전 이미지 조합으로 PDF를 생성할 수 있다.
코드 경로 확인 사항이며, 해당 설정변경 UI 시나리오는 이번 자동 테스트에 없고 수동 재현 완료로 표시하지 않는다.

P1 품질 상한:
AdvancedOfflineToolsView.swift:295–300 (사진 입력을 2000px로 축소), OfflineImageEngine.swift:17–20 (erase/marks 2400px raster), AdvancedOfflineToolsView.swift:348 (다중 PPT 1200px).

P2 잘못된 Excel 열 위치:
OfficeExport.swift:76–84 tableText는 각 행의 존재하는 box만 x정렬 후 탭 연결.
첫 행 A,B / 다음 행 B 위치에만 값이 있으면 다음 행 값이 첫 열로 당겨진다. 공통 열 경계와 빈 셀 보존 필요.

P2 오래 걸리는 작업 취소 UX:
AdvancedOfflineToolsView.swift:203–208 busy 동안 Form 비활성/뒤로가기 숨김, 취소 버튼 없음.
여러 detached 작업은 부모 job.cancel과 자동으로 연결되지 않아 중간 취소/진행률 보강 필요. 일부 경로는 결과 반영 전 취소검사가 있지만 작업 자체 중단과는 다르다.

P2 품질 회귀 테스트 부족:
Book 테스트는 개수·크기·범위, Restore는 크기·유효성, Mesh는 OBJ 합성 데이터 검증 중심.

판정
도구 메뉴와 로컬 실행 경로는 넓게 구현되어 있으나, Competitor app A급 전 항목 완성 상태는 아니다.
