Word export staged flow — 2026-10-01

Word-specific UI now has three stages:
1. Choose source/page scope. Primary: Extract text. No Create action or text editor on this screen.
2. Review/edit recognized text. Primary: Create Word file. No source controls or Extract button. Empty/whitespace-only text disables creation. Explicit type/paste option enters this stage without OCR.
3. Ready file. Primary: Share Word file. Secondary: Preview Word file. No editor or Create action. Back returns to editing and removes the old generated export before rebuilding.

Processing shows progress/cancel instead of an inactive competing primary button. OCR errors stay on input; empty OCR goes to review with an explanation and disabled creation. Existing export limitation (editable text, not original PDF layout) remains visible before creation.
