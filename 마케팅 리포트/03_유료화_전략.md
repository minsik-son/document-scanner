# 03. 유료화 전략 — 무엇을 무료로, 무엇을 유료로

## 1. 원칙

> **"찍고 보관하는 건 평생 무료, 남에게 내보낼 '완성품'을 만드는 건 Pro."**

- **스캔 자체는 돈이 되지 않는다.** Apple 메모·미리보기·vFlat이 무료로 제공한다. 오히려 무료 스캔은 설치와 리뷰를 모으는 엔진이다.
- **사람이 돈을 내는 순간은 마감 직전이다.** "파일이 너무 커서 업로드가 안 된다", "Word로 달라고 한다", "주민번호를 가리고 보내야 한다", "외국어 서류를 읽어야 한다" 같은 상황이다. 이 순간에 해결책을 Pro로 둔다.
- **무료 범위를 숨기지 않는다.** 경쟁 앱 불만 1위가 "스캔한 뒤에야 알려 주는 제한"이다. Pro 배지와 남은 무료 횟수를 미리 보여 준다. 지금 앱도 대체로 그렇게 하고 있다.

## 2. 무료 / Pro 경계 — 추천안

> **시각 자료:** claude.ai 캔버스 "Pageframe 광고 배치 목업"의 '무료 vs Pro' 페이지. 기능 지도 + Tools 배지(Ⓐ) + 첫 탭 체험 화면(Ⓑ) + Me 화면 남은 체험(Ⓒ)
>
> **개발용 확정표:** `06_개발_전달사항.md` 1절

현재 코드 대비 바뀌는 부분은 **굵게** 표시했다.

| 기능 | 현재 | 추천 | 이유 |
|---|---|---|---|
| 스캔, 자동 보정, 톤, 무제한 페이지 | 무료 | 무료 | 획득 엔진. 메모 앱보다 좋아야 한다 |
| PDF 저장·공유·인쇄 (워터마크 없음) | 무료 | 무료 | 핵심 차별점이자 메시지 |
| 검색 가능한 PDF (전체 OCR), 페이지별 텍스트 복사 | 무료 | 무료 | iOS Live Text가 이미 무료로 해 준다. 막으면 손해다 |
| 전체 텍스트 한 번에 공유 | Pro | Pro | 적당한 상위 판매 지점 |
| 서명 (저장 서명 1개), 병합 (2개), 순서 변경, 이미지 내보내기 | 무료 | 무료 | 사용 빈도가 높다. 신뢰를 쌓는 기능 |
| 신분증·QR·화이트보드·스크린샷 이어 붙이기·명함 | 무료 | 무료 | 홈 화면에서 쓰는 습관을 만든다 |
| 폴더·검색·휴지통·백업·Face ID 잠금 | 무료 | 무료 | "내 문서는 내 것" 약속 |
| Word·Excel·PowerPoint·수식 스캔 | Pro + 체험 3회 | Pro + 체험 3회 | 가장 강한 결제 이유 |
| 사진 번역 | Pro + 체험 3회 | Pro + 체험 3회 | 여행·이민·유학 수요. 영상 소재로 좋다 |
| 이미지 도구 (책, 증명사진, 지우개, 색 표시 제거, 복원, 메가 스캔) | Pro + 체험 3회 | Pro + 체험 3회 | 유지 |
| 압축, 암호, 분할, 추출, 워터마크, 타임스탬프, 긴 이미지 | Pro (체험 없음, 바로 결제 화면) | **Pro + "PDF 도구" 묶음 체험 3회** | 압축은 "업로드 용량 초과"라는 마감 직전 고통이다. 한 번 써 보게 하면 전환율이 가장 높을 기능이다 |
| 개인정보 가리기, 양식 채우기 | Pro (바로 결제 화면) | **Pro + 각 1회 체험** | 데모하기 좋은 기능이다. 써 보면 "와" 하는 순간이 나온다 |
| 클라우드 폴더 자동 저장 | Pro | Pro (체험 없음) | 계속 가치를 주는 기능이라 구독 명분이 된다 (심사 3.1.2) |
| 측정, 3D 스캔 | 무료 | 무료. 마케팅에서는 제외 | 스캐너 정체성과 무관하다. 메시지를 흐리지 않도록 스토어 소개에서 뺀다 |
| 광고 제거 | Pro | Pro | 04 문서 |
| **(신규 제안) iCloud 동기화 (iPhone ↔ iPad ↔ Mac)** | 없음 | **Pro** | CloudKit은 사용자 iCloud를 쓰므로 개발자 서버 비용이 0이다. 구독을 이어 갈 가장 좋은 명분이다 |
| **(신규 제안) 파일 이름 규칙·일괄 처리** | 없음 | **Pro** | 개인사업자·영수증 정리 사용자를 위한 반복 가치 |

### 구현 메모

1. `AdvancedOfflineToolsView.locked()`가 Pro 도구를 곧바로 결제 화면으로 보내고 있다. 이것을 `ProToolLockView`(무료 체험 화면)로 보내도록 바꾼다.
2. 그다음 `ProFeature`에 `pdf`(PDF 도구 묶음)와 `smart`(스마트 도구, 1회)를 추가한다.
3. 이렇게 하면 Me 화면의 "My benefits" 표시와 실제 동작이 일치한다.

## 3. 결제 화면을 띄우는 시점

| 순간 | 동작 | 비고 |
|---|---|---|
| 첫 실행, 촬영 중, 저장 직후 | **띄우지 않는다** | 현재 PRD 원칙 유지. 첫인상과 리뷰를 지킨다 |
| Pro 도구를 처음 누를 때 | 체험 화면: "Try free (3 left)"가 주 버튼, "Upgrade to Pro"가 보조 버튼 | 써 본 다음에 결제를 묻는다 |
| 체험을 다 쓰고 다시 누를 때 | 결제 화면 (해당 기능 슬라이드부터) | 보상형 광고로 1회 연장도 제안한다 (04 문서) |
| 3번째 저장 성공 후 | 홈에 1회성 카드 "Pro 7일 무료로 써 보기" (전체 화면 아님) | 습관이 생긴 사용자에게만 보인다 |
| 10MB가 넘는 PDF를 공유하려 할 때 | 공유 시트 위에 "Compress first? (Pro · free try)" 제안 | 상황에 맞는 맥락형 상위 판매 |
| 체험 종료 2일 전 | 알림 (이미 구현됨) | 신뢰 장치. 스토어 소개에도 쓴다 |
| 구독 해지·만료 후 | iOS 18+ 윈백 오퍼 (첫 3개월 50% 등) | App Store Connect 설정만 하면 된다 |

### 온보딩 끝 소프트 페이월

- 첫 스캔 축하 화면 다음에 닫기 쉬운 페이월을 1회 보여 주는 방식이다.
- 업계 데이터상 매출에는 가장 효과적이다. 하지만 지금 브랜드 원칙(첫 실행 결제 화면 없음)과 충돌한다.
- **v1.1에서 분석 도구를 붙인 뒤 50:50 A/B 테스트로 결정**하기를 권한다.
- 판단 기준: 설치 → 체험 전환율, 1점 리뷰 비율, D7 유지율

## 5. 결제 화면 수정 목록

1. **혜택 슬라이드 정정**
   - "Text from any page"는 무료 기능이므로 삭제한다.
   - 대체 슬라이드: "Auto-save to iCloud Drive / Dropbox"(실제 Pro), "Unlimited signatures & merges"
2. **맥락형 시작**
   - `PaywallView(feature:)` 매개변수를 추가해 해당 슬라이드를 첫 장으로 띄운다.
   - 상단 제목 예: "Compress PDF is a Pro tool"
3. **신뢰 문구 강화.** 현재 하단 문구는 "Scanning, PDF and signing stay free. Cancel anytime."이다. 여기에 다음을 더한다.
   - "Your documents stay yours, even if you cancel."
   - "No watermark ever."
4. **체험 타임라인 시각화**
   - 오늘: 전체 사용 → 5일째: 알림 → 7일째: 결제
   - Blinkist가 써서 유명해진 패턴이다. 체험 시작률과 신뢰를 함께 올린다.
5. **가격 표기를 월 환산 우선으로**
   - 연간 카드에 "$2.50/month, billed yearly"가 이미 들어가 있다. 좋다.
6. **(중요) 실제 결제 동작 확인**
   - App Store Connect 실상품 Sandbox 테스트는 아직 남은 출시 항목이다.

## 7. 유료 광고(UA)와의 관계

- 설치 1건당 회수액 = 2.5% × $27 = **약 $0.68**이다.
- 반면 미국 Apple Search Ads의 설치 단가는 $2.25–4.06이다. **이 무료 범위에서는 유료 획득이 적자다.**
- 따라서 성장은 오가닉(ASO, 콘텐츠, 입소문) 중심으로 한다.
- 유료 광고는 아래처럼 전환 의도가 강한 롱테일 키워드에만 하루 $10–20로 시험한다.
  - "scan to word", "compress pdf", "translate document photo"
- 키워드별 결제 전환율이 측정되면 그때 확대한다 (05 문서).
