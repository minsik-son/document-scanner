## 1. 무료 / Pro 확정표

### 1-1. 무료 (평생, 워터마크 없음, 체험·광고와 무관)

| 영역 | 기능 | 코드 |
|---|---|---|
| 촬영·보정 | 문서 스캔(자동 경계·자동 촬영), 원근·그림자 보정, 톤 6종, 밝기·대비·선명도, 여백 다듬기, 무제한 페이지 | `CameraView`, `ReviewView` |
| PDF | 저장·공유·인쇄, 검색 가능한 PDF(전체 OCR), 페이지 텍스트 추출·복사, 페이지 순서 변경, 이미지로 내보내기 | `LibraryTool.ocr/.reorder/.images/.print` |
| PDF | 서명 (저장 서명 1개), 병합 (문서 2개까지) | `DocumentTool.annotate`, `.merge` (`freeMergeDocuments`) |
| 일상 도구 | 신분증 스캔, QR, 스크린샷 이어 붙이기, 화이트보드, 명함 → 연락처 | `DocumentTool.identity`, `SmartTool.businessCard` 등 |
| 보관·보안 | 폴더, 즐겨찾기, 검색, 휴지통, 백업·복원, Face ID 잠금 | – |
| 카메라 유틸 | 측정, 3D 스캔 | `AdvancedTool.measure/.mesh` (스토어 소개에서는 제외) |

### 1-2. Pro — 무료 체험 있음 (기기당, 묶음 안에서 횟수 공유)

| 체험 묶음 (`ProFeature`) | 횟수 | 포함 도구 | 현재 | 변경 |
|---|---|---|---|---|
| `office` | 3 | Word, Excel, PowerPoint, 수식 스캔 | 있음 | 유지 |
| `translate` | 3 | 사진 번역 | 있음 | 유지 |
| `image` | 3 | 책 페이지, 증명사진, 스마트 지우개, 색 표시 제거, 사진 복원, 메가 스캔 | 있음 | 유지 |
| **`pdf` (신규)** | 3 | 압축, 암호, 분할, 페이지 추출, 워터마크, 타임스탬프, 긴 이미지 | 체험 없이 바로 결제 화면 | **체험 신설** |
| **`redact` (신규)** | 1 | 개인정보 가리기 | 바로 결제 화면 | **체험 1회 신설** |
| **`fillForm` (신규)** | 1 | 양식 채우기 | 바로 결제 화면 | **체험 1회 신설** |

### 1-3. Pro — 체험 없음

- 광고 제거
- 클라우드 폴더 자동 저장 (`SmartTool.autoSave`)
- 전체 텍스트 한 번에 공유
- 저장 서명 무제한
- 병합 무제한
- (다음 업데이트 후보) iCloud 동기화(CloudKit), 파일 이름 규칙·일괄 처리

### 1-4. 코드 변경

1. `SubscriptionStore.swift` `ProFeature`에 `pdf`, `redact`, `fillForm`을 추가한다. `title`은 각각 "PDF tools", "Hide personal info", "Fill a form"이다.
2. `ProTrials.limit`(현재 고정 3)을 기능별 한도로 바꾼다: `office/translate/image/pdf = 3`, `redact/fillForm = 1`.
3. `DocumentTool`(`DocumentToolsView.swift:22`) 중 Pro인 도구를 `ProFeature.pdf`로 매핑한다. 대상: watermark, timestamp, longImage, split, extract, compress, protect.
4. `SmartTool`(`AdvancedOfflineToolsView.swift:1251`)을 다음처럼 매핑한다: `redact → .redact`, `fillForm → .fillForm`, `autoSave → nil`(체험 없는 Pro).
5. **체험 차감 시점:** 지금은 "Try free"를 누르는 순간 차감된다. **결과물을 저장하거나 공유하는 데 성공했을 때 차감**하도록 바꾼다. 실패하거나 취소한 시도로 체험이 사라지면 1점 리뷰가 나온다.
   - 구현이 크면 이 항목은 두 번째 순위로 미뤄도 된다.

## 2. Pro 도구를 눌렀을 때의 흐름 (모든 진입점 동일)

```
Pro 도구 탭
 ├─ Pro 사용자 → 바로 도구
 ├─ 체험 남음 → 체험 화면 (Ⓑ)    주 버튼 "Try free (N left)" / 보조 "Upgrade to Pro"
 ├─ 체험 소진 → 소진 화면 (⑤)    주 버튼 "Upgrade to Pro" / 보조 "Watch a short ad · 1 more use" (묶음당 하루 1회)
 └─ 체험 없는 Pro → 결제 화면 (해당 기능 슬라이드부터)
```

**현재 버그 (반드시 수정):**
- `AdvancedOfflineToolsView.locked()`가 Tools 탭 그리드(스마트·변환·이미지·PDF 섹션)에서 무료 사용자를 곧바로 `paywall = true`로 보낸다.
- 반면 `ProToolLockView`(체험 화면)는 `QuickToolView` 경로(홈 Quick tools, 문서 Tools 메뉴)에서만 나온다.
- Me 화면에는 "3 of 3 free left"가 표시되는데, Tools 탭에서는 체험할 수 없다.
- PDF Pro 도구(`PDFToolFlows.swift` `PDFToolFlow`, 155·172번 줄 부근)는 사용자가 문서를 고른 **뒤에** `paywall = true`로 결제 화면을 띄운다. 문서를 고르고 나서야 막히는 구조라 실망이 크다.
- **수정:** Tools 탭도 위 흐름을 따르게 한다. `PDFToolFlow`는 문서 선택 **전에** 체험 화면(또는 체험 1회 사용 확인)을 거치게 한다.

**`ProToolLockView` 변경:**
- 체험이 남았을 때: "Try free"를 `CTAButtonStyle`(주)로, "Upgrade to Pro"를 보조로 바꾼다. 현재는 반대다.
- 문구 예: "Compress PDF is part of Pro. You have 3 free tries of PDF tools on this iPhone."
- 하단 보조 문구: "Files you make with a free try are yours to keep."
- 체험을 다 썼을 때: 보상형 광고 버튼을 추가한다 (4-3절).

**Tools 탭 배지 (Ⓐ):**

| 상태 | 배지 |
|---|---|
| 무료 도구 | 없음 |
| 체험이 남은 Pro 도구 | "3 free" / "1 free" (남은 횟수) |
| 체험을 다 썼거나 체험이 없는 Pro 도구 | 기존 "PRO" 배지 |
| Pro 사용자 | 배지 없음 |

**Me 화면 "My benefits" (Ⓒ):**
- 6개 묶음 + "No ads" + "Auto-save"를 표시한다.
- 아래에 "Scanning, PDF, text recognition and signing are always free." 문구를 넣는다.

## 3. 결제 화면 (`PaywallView.swift`)

1. **잘못된 혜택 슬라이드 삭제:**
   - `ProFeatureCarousel.slides`의 "Text from any page"를 삭제한다. OCR·텍스트 복사·검색은 무료이므로 Pro 혜택이 아니다.
   - 대체 슬라이드: "Auto-save to iCloud Drive or Dropbox"(아트 `art-auto-save` 있음), 필요하면 "Unlimited signatures & merges"
2. **진입 맥락 매개변수:**
   - `PaywallView(start: PaywallStart)`를 추가한다. `PaywallStart`는 `.feature(ProFeature)`, `.smartTool`, `.noAds`, `.general` 중 하나다.
   - 캐러셀은 해당 슬라이드부터 시작한다.
   - 광고 카드의 "Remove ads with Pro" 링크는 `.noAds`로 연다 (⑥).
3. **하단 신뢰 문구:** "Scanning, PDF and signing stay free. Your documents stay yours, even if you cancel."
4. **가격** (App Store Connect + `Configuration/Scanner.storekit`)

| 상품 | 가격 | 비고 |
|---|---|---|
| `com.documentscanner.pro.monthly` | $4.99 | 유지 |
| `com.documentscanner.pro.yearly` | $29.99, 7일 무료 체험 | 유지 |
| `com.documentscanner.pro.lifetime` | **$59.99** | 출시 30일만 $39.99. 출시일에 $39.99로 두고, App Store Connect 가격 일정 기능으로 30일 뒤 $59.99로 바뀌게 예약한다 |

   - 한국 가격은 수동 설정한다: 월 ₩6,600 / 연 ₩39,000 / 평생 ₩79,000 (출시 한정 ₩55,000)
   - 결제 화면에서 평생 카드는 출시 기간에 "Founding price" 리본을 단다.
   - 번들 ID와 상품 ID는 최종 앱 이름이 정해지면 함께 바꾼다. 현재 `com.documentscanner.*`이다.
5. **결제 화면 자동 노출은 하지 않는다.** 첫 실행, 촬영, 저장 직후 금지다.
   - 대신 **3번째 저장 성공 뒤 홈에 1회성 카드**를 띄운다: "Try Pro free for 7 days". 닫을 수 있고, 다시 뜨지 않는다.

## 4. 광고 (무료 사용자만)

### 4-1. 홈 (`HomeView.swift` — `HomeAdvertisementSlot`, 현재 61번 줄 부근)

- 검색창 바로 아래에서 **문서 목록 3번째 행 아래**로 옮긴다. 문서가 3개 미만이면 목록 맨 끝에 둔다.
- 카드 높이를 줄이고(목업 ②: 썸네일 72pt + 제목 + CTA), 가능하면 이미지 광고를 우선 요청한다. 동영상이 오면 음소거로 시작하는 현재 설정을 유지한다.
- 카드 하단에 링크를 추가한다: "Remove ads with Pro" → `PaywallView(start: .noAds)`
- **설치 후 24시간**은 슬롯을 숨긴다. `firstLaunchAt`을 UserDefaults에 저장하고 `HomeAdEligibility`에 조건을 추가한다.

### 4-2. Tools 화면 (`AdvancedOfflineToolsView.swift:107` 부근)

- 위치는 유지한다. 같은 "Remove ads with Pro" 링크를 추가하고, 24시간 숨김도 같은 규칙으로 적용한다.

### 4-3. 보상형 광고 (신규)

- 위치: 체험을 다 쓴 `ProToolLockView`의 보조 버튼 "Watch a short ad · 1 more use"
- 보상: 해당 묶음의 체험 1회. 묶음당 하루 1회까지이고, 그 아래 "1 ad unlock left today"를 표시한다.
- 광고가 로드되지 않았으면 버튼을 숨긴다. 기다리게 하지 않는다.
- 개발 중에는 Google 공식 iOS 보상형 테스트 단위 `ca-app-pub-3940256099942544/1712485313`를 쓴다.
- 기존 광고 게이트(Pro·잠금·오프라인·UI 테스트)를 그대로 적용한다.

### 4-4. 유지하거나 금지할 것

- 저장 완료 후 전면 광고(`CompletionAdvertisement`)는 **계속 꺼 둔다** (`completionAdEnabled: false`).
- 앱 시작 광고, 하단 고정 배너, 카메라·검토·저장 흐름 안의 광고는 금지한다.
- Release 출시 전 준비 사항:
  - 실제 AdMob ID
  - UMP 동의와 설정의 "Privacy options"
  - SKAdNetwork 식별자
  - App Store 개인정보 라벨
  - 공개 개인정보처리방침
  - **ATT 요청 없음, 비맞춤형 광고**
- 이것이 준비될 때까지 `testAdsEnabled`의 Release `false`는 유지한다.
- `PrivacyView`의 광고 문구도 위 배치에 맞게 고친다. 홈과 Tools, 보상형을 언급하고 "no full-screen ads"를 유지한다.

## 6. 완료 기준 (수용 테스트)

- [ ] 무료 사용자가 Tools 탭에서 Word를 누르면 결제 화면이 아니라 체험 화면이 뜨고, "Try free (3 left)"가 주 버튼이다.
- [ ] 압축 1회 + 암호 1회를 쓰면 PDF 도구 배지가 "1 free"가 되고, Me 화면도 "1 of 3 left"로 같다.
- [ ] 개인정보 가리기 1회를 쓴 뒤 다시 누르면 소진 화면이 뜬다. 보상형 광고 시청을 완료하면 1회 더 쓸 수 있고, 같은 날 두 번째는 불가하다.
- [ ] 체험 중 취소하거나 실패하면 횟수가 줄지 않는다 (1-4의 5번을 구현한 경우).
- [ ] 결제 화면 어디에도 OCR·텍스트 복사가 Pro 혜택으로 나오지 않는다.
- [ ] Compress PDF에서 연 결제 화면은 "Lock & compress PDFs" 슬라이드부터, 광고 링크에서 연 결제 화면은 "No ads" 슬라이드부터 시작한다.
- [ ] 홈 광고는 문서 3번째 아래(또는 목록 끝)에만 있고, 설치 후 24시간 동안은 보이지 않는다.
- [ ] Pro 구매·복원 직후 홈·Tools 광고와 보상형 버튼이 즉시 사라진다.
- [ ] 저장 후 전면 광고가 어떤 경로에서도 뜨지 않는다.
- [ ] 공유 시트에 문서 제목 파일명이 보인다.
- [ ] 평생 상품 가격이 StoreKit 설정에서 $59.99다 (출시 한정가는 App Store Connect 일정으로 처리).

## 7. 하지 말 것

- 주간 구독 상품 추가
- 첫 실행이나 저장 직후 결제 화면 자동 노출
- 결과물에 워터마크를 소급해서 붙이기, 구독 만료 후 기존 문서 잠그기
- 경쟁사 이름(CamScanner, vFlat, Lens)을 앱 문구나 메타데이터에 쓰기
- 측정·3D 스캔을 결제 화면 혜택으로 쓰기 (무료 기능이다)
